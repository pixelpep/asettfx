    Draw your pixel-art letters, in the page or in Aseprite, and turn them into a real font. Digiface is made for GB Studio projects (it has the GB Studio character layout and its two default fonts) and for any design work that needs a crisp pixel typeface: the font installs like any other and stays sharp at sizes that are multiples of the cell height.
    
    
      
      
    1. Choose a character set, the cell size and the spacing in the cards. A guide font shows the character to draw in each cell.
      2. 
      
    2. Press Edit to draw right here (brush, eraser, width of each character), or download the Template and draw on it in Aseprite.
      3. 
      
    3. Download the Drawing: a PNG with what you drew, without any guide.
      4. 
      
    4. In Aseprite, the Digiface extension turns the PNG into a font: File ▸ Scripts ▸ Digiface ▸ Export as TTF…. Download the .aseprite-extension file and double-click it.
      5. 
    
    
    
    GB Studio: tick GB Studio next to Baseline ticks. The layout, the 8 x 8 cells and the 16 columns are fixed, and the colors are the ones of GB Studio's palette. The drawing you download is the font image GB Studio reads: put it, with its .json (the window offers it), in the assets/fonts folder of your project.
