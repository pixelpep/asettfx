    Draw your pixel-art letters, in the page or in Aseprite, and turn them into a real font. Pick what you want to do:
    
    
    
      
      
      
    
    
    
    
      
    Make the grid, draw on it in Aseprite, and let the extension write the font.
    
      
      
        
    1. Choose the character set, the cell size and the spacing in the settings. The guide font shows the character to draw in each cell.
      2. 
        
    2. Download the Template (a PNG with the settings inside) and open it in Aseprite.
      3. 
        
    3. Draw each letter in black on a layer above the template, which is only a guide. For a variable-width font, paint pure magenta (#FF00FF) over the unused columns on the right of each letter.
      4. 
        
    4. Hide the template layer. Install the Digiface extension (download the .aseprite-extension file and double-click it), then run File ▸ Scripts ▸ Digiface ▸ Export as TTF…. The extension lists any problem first, then exports the TrueType font (.ttf).
      5. 
      
    
    
    
    
    
      
    Draw a font for a GB Studio project, using the same folder and the same grid as GB Studio's own fonts.
    
      
      
        
    1. Tick GB Studio at the top of the Guide column of the settings. The layout, the 8 x 8 cells and the 16 columns are fixed, the colors are the ones of GB Studio's palette, and GB Studio's own font is the guide.
      2. 
        
    2. Press Edit pixel font to draw right here, or download the Template and draw on it in Aseprite.
      3. 
        
    3. Download the Drawing. The window offers the .json that goes with it (it tells GB Studio where the euro sign, the curly quotes and the other characters of the 0x80-0x9F block are); keep it ticked.
      4. 
        
    4. Copy the PNG and its .json, with the same name, into the assets/fonts folder of your GB Studio project. GB Studio reads the PNG itself, so no TTF is needed.
      5. 
      
    
    
    
    
    
      
    Draw a pixel font in the page with Digiface Matrix, and download it as a TTF. Aseprite is not needed.
    
      
      
        
    1. Choose the character set and the spacing. Optionally pick a pixel font as the guide, and tick Use the guide font's cell size at the top of the Cells column of the settings to take the cell size it needs.
      2. 
        
    2. Press Edit pixel font. Draw with the brush and the eraser; with a variable-width font, set the width of each character with the Width tool. The settings stay editable while you draw, and the drawing follows its characters.
      3. 
        
    3. Press Font (TTF) and give the font a name: the window tells you which characters have no drawing and are left out. Install the .ttf like any other font: it stays sharp at sizes that are multiples of the cell height.
      4. 
        
    4. To refine the drawing in Aseprite, download the Drawing (a PNG without any guide) instead, and export it there with the Digiface extension: File ▸ Scripts ▸ Digiface ▸ Export as TTF…
