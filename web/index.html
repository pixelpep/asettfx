    How to use Digiface
    
  
    Draw your pixel-art letters in Aseprite and turn them into a real font. Digiface is made for GB Studio projects (it has the GB Studio character layout and its two default fonts) and for any design work that needs a crisp pixel typeface: the font installs like any other and stays sharp at sizes that are multiples of the cell height.
    
  
    For a GB Studio font, tick GB Studio next to Baseline ticks: the layout, the 8 x 8 cells and the 16 columns are fixed, and the template is an indexed PNG in the colors of GB Studio's palette. In Aseprite, draw the characters with the darkest color (the second of the palette), keep the palest as the background and use the magenta for the widths. Then export the image as a PNG (File ▸ Export As…) and put it, with the GB Studio .json of the same name, in the assets/fonts folder of your project.
    
  
      
    
    1. Choose a character set, the cell size and the spacing here. A guide font shows the character to draw in each cell.
      2. 
    
    2. Download the PNG template.
      3. 
    
    3. Open it in Aseprite and draw each glyph in black on a layer above it. The template is only a guide.
      4. 
    
    4. For a variable-width font, paint pure magenta #FF00FF over the unused columns on the right of each glyph. Without magenta the font is monospace.
      5. 
    
    5. Hide the template layer, then choose File ▸ Scripts ▸ Digiface ▸ Export as TTF….
      6. 
  
    
  
    The export needs the Digiface for Aseprite extension: download the .aseprite-extension file and double-click it.
