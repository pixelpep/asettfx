# Digiface 0.1.0

Draw pixel-art glyphs in Aseprite on a template grid, and export them as a TrueType font (`.ttf`) for Figma, game engines and design tools.

## What is in this release

- **Template generator** (`web/index.html`, no install, works offline in a browser): makes a PNG grid template with a faint ghost of each character to draw, baseline ticks and, for variable-width fonts, optional pre-filled magenta width columns. The settings are stored inside the PNG.
- **Aseprite extension** (`digiface-0.1.0.aseprite-extension`): *File > Scripts > Digiface > Export as TTF...*
  - Reads every visible layer over white: black pixels are the glyphs, pure magenta (`#FF00FF`) marks the unused width of a glyph.
  - Spacing follows the image: magenta found means variable spacing, none means monospace, and you can choose monospace anyway.
  - Lists problems before exporting, with the row and column of each character concerned (errors block, warnings do not).
  - Writes crisp pixel outlines at 64 units per pixel, so the font is sharpest at multiples of the cell height (8, 16, 24... px).
  - Typographic quotes, dashes and the no-break space reuse your plain glyphs, so a typed apostrophe stays in pixel art.

## Install

Download `digiface-0.1.0.aseprite-extension` below and double-click it, or use *Edit > Preferences > Extensions > Add Extension* in Aseprite. Aseprite asks you to approve each file the script opens.

## Workflow

1. Open `web/index.html`, choose a character set, spacing and cell size, and download the PNG template.
2. Open the PNG in Aseprite and draw each glyph in black on a layer above it. For variable widths, paint magenta over the unused columns on the right of each glyph.
3. Hide the template layer, then run *Export as TTF...*.

## Known limits

- No kerning and no hinting. Characters that were not drawn are left out of the font.
- Tried in Aseprite 1.3.16 on macOS. Other versions and systems have not been tested.
- The ghost characters of the template use a system font, so they look different from one system to another and are crowded for accented characters in 8 px cells.
