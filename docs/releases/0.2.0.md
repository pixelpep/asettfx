# Digiface 0.2.0

Draw pixel-art glyphs in Aseprite on a template grid, and export them as a TrueType font (`.ttf`) for your game (GB Studio and other engines) and for design work that needs a crisp pixel typeface.

Digiface has two tools:

- **Digiface Matrix**, the template generator (`web/index.html`, no install, works offline in a browser): makes a PNG grid template with a faint ghost of each character to draw, baseline ticks and, for variable-width fonts, pre-filled magenta width columns. The settings are stored inside the PNG.
- **Digiface for Aseprite** (`digiface-0.2.0.aseprite-extension`): *File > Scripts > Digiface > Export as TTF...*

This is the first version published under the name Digiface. It replaces 0.1.0, which was published as ASETTFX and withdrawn.

## What is new since 0.1.0

- **New name**, internal names included: the PNG chunk and the sprite property are `digiface`, the sidecar file is `<name>.digiface.json`. Templates made with the old name are not read: make them again.
- **Pixel fonts as guides.** The ghost characters can be drawn with one of ten bundled pixel fonts (Bytesized, Alkhemikal, Digital Disco, Grape Soda, Kiwi Soda, Minecraft Standard, GB Studio Mono and Variable) or with a pixel font file from your computer, pixel for pixel. A button sets the cell size and baseline the font needs.
- **GB Studio layout** now follows the real grid of GB Studio's fonts (Windows-1252 order, 11 unused cells).
- **New page layout** with collapsible cards (Guide, Cells, Spacing), variable spacing by default, a left padding and a bottom margin for the guide characters, and a "?" button that explains the steps.
- Fixes: fractional numbers in the settings are rejected, font names with accents are accepted.

## Install

Download `digiface-0.2.0.aseprite-extension` below and double-click it, or use *Edit > Preferences > Extensions > Add Extension* in Aseprite. Aseprite asks you to approve each file the script opens.

To use Digiface Matrix, download the source code zip of this release and open `web/index.html`.

## Workflow

1. Open Digiface Matrix, choose a character set, spacing and cell size, and download the PNG template.
2. Open the PNG in Aseprite and draw each glyph in black on a layer above it. For variable widths, paint pure magenta (`#FF00FF`) over the unused columns on the right of each glyph.
3. Hide the template layer, then run *Export as TTF...*. The dialog lists problems with the row and column of each character (errors block, warnings do not).

## Known limits

- No kerning and no hinting. Characters that were not drawn are left out of the font.
- Tried in Aseprite 1.3.16 on macOS only. Other versions and systems have not been tested.
- Each pixel is 64 font units, so the font is sharpest at multiples of the cell height (8, 16, 24... px).
